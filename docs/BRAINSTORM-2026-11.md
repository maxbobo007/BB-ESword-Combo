**值得借鉴的机制**
- **ConjuGato**：标出不规则形式，相似的动词放在一起学。
- **SpanishDict**：练什么由用户自己选。
- **Clozemaster / Lingvist**：在句子里填变位，同时学"什么时候用"。
- **Anki**：卡片粒度要选对。
- **扇贝、百词斩**："认识 / 不认识"快速剔除熟词。
- **墨墨**：把记忆曲线和未来的复习量画出来给用户看。
- **Wordle / NYT**：每天限量一局，做完就停。
- **Duolingo**：错题自动回练、断签保护。

**不要照搬**：联赛和排行榜、强推付费墙、纯限时刷题。

**我们的真实差异**：中文释义 + 成体系背变位 + 主动拼写 + 西班牙西语 + 免费离线。
**我们的明显短板**：没有发音、没有间隔复习、不能按动词背、例句单调、填字比"斩"慢、释义没有经过母语者审核。

## 2. 学习体验（学习体验设计师）

- **"没法背"的根本原因**：缺少"先呈现"这一步，而且变位交错得太早。`items.ts` 每个动词只随机抽 1 个时态和 1 个人称，同一个动词在一局里几乎不会出现第二次。
- **填字会泄露要学的部分**：随机给出的字母、交叉格可能正好是词尾；答案长度也能区分时态；复合时态只填分词，6 个人称的答案一模一样。
- **名词路径**：词卡（西语、中文、图、发音、例句）→ 二选一 → 拼写 → 7×7 主题填字 → 到期后进入跨主题填字。
- **动词路径**：一个单元 = 1 个动词 × 1 个时态。看表 → 填词尾 → 填整词 → 句子填空 → 该动词专属填字。学过 2 个以上时态后做同一动词内的辨别；同一时态学过 3 个以上动词后做跨动词练习；复习时完全交错。
- **首页**："今日学习"一键开始 + "继续上次" + 自由练习；等级只在首次打开时问一次；棋盘和难度移出首页。
- **P0 易用性问题**：
  - 没有重音键，而且输入 E 也算 É 对；
  - 变位填字泄露词尾；
  - 进度不保存；
  - 手机上的 11×11 棋盘格子太小。
- **P1 易用性问题**：
  - 例句卡遮挡棋盘，6 秒就消失，读不完；
  - 变位线索太挤；
  - 错误反馈不具体；
  - 结果页没有学习价值。

## 3. 增长与习惯（增长专家）

- **用周目标代替每日连胜**：目标每周 5 天，自带 2 天补签。奖励只和"学到了"挂钩，不发积分、宝石。
- **"今日学习"**：到期复习 + 5–8 个新词 + 1 个动词单元，≤ 10 分钟；到期太多时截断，剩下的顺延到明天。
- **本地通知**：第一次学完今日内容后才问要不要提醒；每天最多 1 条；当天学完就不发；连续 3 天没点开就改成隔天，7 天没点开就停。
- **内测期的数据**：本地事件表 + "导出我的数据"；第 0、7、14 天各做一次问卷；每周和 1–2 人聊 15 分钟。
- **v1.0 之后**：社群（小红书、豆瓣、B 站，发"一个动词怎么背完"的短教程）；分享卡片不带任何奖励。
- **收费的顺序（只看方向）**：打赏 → 买断 Pro → 同步订阅。

## 4. 产品战略（战略负责人）

- **定位**：主打变位，单词作为入门。
- **版本节奏**：v0.3 按动词背 → v0.4 每天回来 → v0.5 内容质量 + iOS → v0.6 进度不丢 → v1.0 上架准备。
- **每个版本要验证的假设**：
  - 按动词背是否比随机出题记得更牢；
  - 复习 + 提醒能不能让人每天回来；
  - 内容质量是不是瓶颈；
  - 用户是否真的有多台设备；
  - 陌生人能不能自己上手。
- **需要拍板的问题**：主打什么、走什么渠道、同步要不要进 v1.0（建议看数据再定）。

## 5. 风险评审（唱反调）

- **填字只适合"拼写巩固 + 奖励关卡"**：它比卡片慢 2–3 倍；给出的字母会让答对率虚高；背变位不如变位表。
- **"决定学什么"的是棋盘生成器，不是学习者或复习调度**，所以：
  - 带重音的形式和长词很少能上棋盘；
  - 以后的"今日学习"拼不成棋盘；
  - 同形答案被去重后，变位表会少一格（hablaba 的 yo 和 él 形式相同）。
- **模板例句的硬伤**：
  - "Antes yo vivía en Madrid a menudo"语义不通；
  - 每句都带主语代词，不符合西语习惯；
  - supe、pude 在过去时里意思会变。
- **AI 起草 + AI 校对不是独立核对**：最低补救方案是请母语老师审核高频内容，约 200–400 元；没审核过的内容不进复习。
- **最可能失败的地方是 M1**（自动拼棋盘 + 按填字结果给复习打分）。
- **建议砍掉或推迟**：B1 的 3 个时态、手机上的 11×11、多种新题型（只保留变位表）、同步（先做导出导入）、iOS（等安卓验证有效）。
